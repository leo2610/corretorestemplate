# Essenza Imóveis — template demonstrativo

## Como executar
1. Extraia a pasta do projeto.
2. Abra `index.html` no navegador. Não é necessário instalar dependências.

## Personalização antes de publicar
- Troque nome, logotipo, telefone e textos pelos dados reais do corretor.
- Atualize o número de WhatsApp nos dois links `wa.me` do arquivo `index.html`.
  Use o formato internacional, apenas números: código do país + DDD + telefone.
  Exemplo ilustrativo: `5511999999999`.
- Substitua os três imóveis de demonstração por imóveis reais e atualize os atributos
  `data-type`, `data-purpose` e `data-location`.
- As imagens usam URLs do Unsplash; substitua-as por fotos autorizadas dos imóveis.
- Ajuste a seção de experiência: os números exibidos são ilustrativos.
- O botão de WhatsApp abre uma conversa diretamente; não há envio de e-mail nem formulário.

## Arquivos
- `index.html`: estrutura semântica da página.
- `style.css`: estilos organizados por seção e responsividade.
- `script.js`: menu mobile, filtros, favoritos visuais e ano automático.
